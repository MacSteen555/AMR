# Insights Module Redesign

**Date:** 2026-03-09
**Status:** Draft

## Problem

1. Single-location teams see a redundant team insights view identical to the location view
2. Standard (non-AI) insights are too dashboard-y — they restate what Google already shows
3. AI-generated reports are buried in collapsible details tags with no navigation, history, or discoverability
4. No clear mental model for team vs location AI reports

## Design

### Auto-Collapse for Single-Location Teams

When a team has only 1 location:
- Nav "Insights" link resolves directly to `/locations/[locationId]/insights`
- No team-level insights page is shown
- Report generation is location-scoped only (prevents wasting credits on a duplicate team report)
- Team-level pages appear automatically once a second location is added

### Route Structure: Tabbed Insights + Reports

Both `/teams/[teamId]/insights` and `/locations/[locationId]/insights` use two tabs:

- **Insights** (default) — live standard analytics, always free
- **Reports** — AI-generated report library, requires paid tier

The Insights tab includes a CTA to generate a report:
- Paid users: one-click path to Reports tab with generation
- Free users: upsell nudge to upgrade to a tier with AI reports

### Insights Tab — Standard Analytics

Always live, no credits required. Content adapts based on scope.

#### Team-Scoped View (2+ locations)

| Section | Description |
|---|---|
| Portfolio KPIs | Avg rating, total review volume, overall response rate, sentiment momentum (vs prior period) |
| Comparative charts | Multi-line trend charts — each location as a line, team average as reference. Covers rating over time and response rate over time |
| Location leaderboard | Ranked table sorted by performance gaps — makes it obvious which location needs attention |
| Reply gap analysis | Unanswered negative reviews older than N days, broken out per location |
| Review velocity | Day/time heatmap showing when reviews come in across the portfolio |
| Keyword theme frequency | Top themes trending up/down across all locations (lightweight, no AI) |

#### Location-Scoped View

| Section | Description |
|---|---|
| KPIs | Same metrics scoped to this location, with "vs prior period" delta |
| Trend charts | Single-line with prior period overlay for comparison |
| Reply gap | Prioritized list of unanswered reviews for this location |
| Review velocity | Day/time patterns for this shop |
| Keyword themes | What customers are talking about at this location specifically |
| Anonymous review ratio | Flag spikes in anonymous reviews as potential fake/competitor signal |

### Reports Tab — AI Report Library

Dedicated home for all AI-generated reports. Replaces the current buried `<details>` accordion.

#### List View

Each row displays:
- Scope badge (team name or location name)
- Period window (30d / 90d / 6m / 1y)
- Date generated
- Generated by (user name)
- Sentiment score badge (quick visual)

#### Actions

- **Generate Report** button — costs 3 credits, gated by subscription tier
- Filter by period window
- Click any row to view full report

#### Report Detail View

Same rich display as current AIInsightsPanel:
- Sentiment gauge + momentum score
- Executive summary with rating trend
- Top action item
- Risk alerts
- Strengths & weaknesses
- Emerging topics
- Recommendations (sorted by impact/effort)
- Customer persona
- Notable quotes with review references
- Response strategy

### New Standard Insight Features (No AI Required)

These are the insights that differentiate AutoMyReply from just looking at Google Maps:

1. **Reply gap analysis** — prioritized list of unanswered reviews with age, rating, and urgency. Actionable, not just informational.

2. **Review velocity + day/time patterns** — when reviews arrive (day of week, time of day). Helps owners understand customer behavior cycles.

3. **Keyword theme analysis** — lightweight theme clustering from review text. No AI credits needed. Shows trending themes (up/down) over time. Acts as a natural funnel to "generate full AI report for deeper analysis."

4. **Sentiment momentum** — rating trend direction and velocity vs prior period. Google shows a static average; we show the trajectory.

5. **Anonymous review ratio** — percentage of anonymous vs named reviews, broken out by rating. Spikes in anonymous negative reviews flag potential fake reviews.

6. **Rating-to-reply correlation** — track whether response behavior correlates with subsequent review patterns. Motivates owners to reply.

### Data Model Changes

No schema changes needed for the insights table — AI reports already store team_id/location_id, period_window, and generated_at which support the report library view.

Standard analytics are computed on the fly from the existing `google_reviews` table (same as current `computeAnalytics` / `computeTeamAnalytics` functions, extended with new calculations).

### Future Opportunities (Not In Scope)

- Cross-team comparison (for users managing multiple teams/brands)
- Side-by-side report comparison (compare this month's report to last month's)
- Google contributor profile enrichment (no API available currently — revisit if Google adds this)
- Recommendation tracking (mark AI recommendations as done/in-progress)
